# Josh Fowler portfolio

Copy index.html, projects.html, about.html, styles.css, and .nojekyll to the root of the josh-fowler-hub.github.io repository.

In GitHub Settings > Pages, choose Deploy from a branch, main, and / (root).

The Daily Learning links point to /daily-learning/, hosted by the separate daily-learning repository.

This starter uses the supplied TITAN colors, spacing, fonts, and gradient. Inter and JetBrains Mono are used when installed; otherwise the declared system fallbacks apply.

Edit the HTML to add verified project details, a biography, resume, and contact links. No build step is required.
